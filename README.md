## 使用方法
### 主程序
直接python打开`main.py`即可，需要安装以下依赖。
``` bash
pip install bs4 requests
```
#### 注意
- 使用鼠标右键点击关闭程序。
- 程序永远置顶。
- `base_url`为hydrooj中的域的地址
- `base_url`，用户名，密码保存在`config.json`
